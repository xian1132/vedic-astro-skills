# 案例分析 PPT：赵一鸣零食 · 战略地图与战略执行分析

基于平衡计分卡（BSC）的上市公司战略案例分析作业，公司选取 **赵一鸣零食**（鸣鸣很忙集团核心品牌）。

## 文件说明

| 文件 | 说明 |
|------|------|
| `赵一鸣零食_战略地图案例分析.pptx` | 最终汇报 PPT（29 页，16:9，v2 现行版） |
| `赵一鸣零食_战略地图案例分析_v1原版备份.pptx` | 首版备份（25 页，未含已汇报小组反馈调整） |
| `build_ppt.py` | PPT 生成脚本（python-pptx），可重复生成 |

## 内容结构（对应作业五大模块）

- **研究框架页** —— 分析逻辑主线：背景→环境分析→战略提出→战略地图→执行评价（闭环）
1. **案例介绍** —— 企业背景、创始人故事与发展历程、商业模式（多快好省）
2. **竞争战略分析** —— PEST 宏观环境（含关键数据条）、波特五力模型、SWOT 分析、**SWOT 战略矩阵（分析→战略推导）**
3. **战略类型与战略推导** —— 总成本领先战略、总体战略与三大战略主轴、**战略优劣势（优缺）评价与应对措施**
4. **战略地图（BSC 四维度）** —— 财务 / 客户 / 内部流程 / 学习与成长，含因果驱动闭环及各维度目标与 KPI 详解
5. **分析与讨论** —— 战略执行评价（目标达成对照）、四维度偏差原因分析、数据口径修正建议、**实践借鉴与启示**、结论

## v2 调整说明（依据已汇报小组反馈）

1. 新增「研究框架」页 + 「SWOT 战略矩阵」页，使「先分析、后战略」的推导逻辑显性化；
2. 新增「战略优劣势评价」页，突出所选战略的优点、风险/缺点与应对措施；
3. 强化 PEST / 波特五力的具体数据支撑；
4. 新增「实践借鉴与启示」页，提炼对行业实践发展的普适借鉴价值。

## 数据来源

PPT 数据以「豆包数据支撑报告」为准，核心来源：鸣鸣很忙集团 2024 招股书及年报、赵一鸣官网、
GeoQ 智图行业蓝皮书、美团闪购行业白皮书。关键口径：单店营收区分供货收入/门店 GMV；
毛利率分公司层/加盟商层/自有品牌；会员数据按集团合并口径。
